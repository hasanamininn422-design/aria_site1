# وضعیت اجرای آریا کالر — ۱۷ سپتامبر ۲۰۲۶

این commit یک مرحله قابل ساخت از پروژه است، نه تحویل production-ready کل نیازمندی‌ها.

## پیاده‌سازی‌شده
- Next.js 15 / React 19، صفحات فارسی RTL، هدر موبایل، لوگوی ارائه‌شده، ویدیوی Hero و کنترل توقف، رعایت reduced motion، پالت سرمه‌ای/طلایی/کرم.
- صفحه اصلی، معرفی، خدمات و ۸ جزئیات خدمت، آرشیو تصویری با فیلتر و جستجو، ۴ صفحه جزئیات تصویر، قبل/بعد قابل کنترل با صفحه‌کلید، ابزار بررسی هماهنگی پالت.
- فرم‌های مشاوره، بازدید و درخواست قیمت، با وضعیت انتظار، موفقیت، خطا و حفظ ورودی هنگام خطا.
- API واقعی POST /api/requests با Prisma/PostgreSQL، اعتبارسنجی سرور، کنترل Origin، سقف اندازه streaming، honeypot، محدودیت اتمیک ساعتی بر شماره تماس و کل سایت؛ اعلان دیتابیسی برای مدیران موجود در تراکنش مشترک.
- در نبود تنظیمات سرور، ثبت غیرفعال و API برابر 503 است؛ موفقیت جعلی نمایش داده نمی‌شود.
- مدل داده و SQL migration اولیه؛ نقش‌های USER/EDITOR/ADMIN/SUPER_ADMIN و وضعیت‌های کامل درخواست تعریف شده‌اند، ولی صرف تعریف نقش به معنی پیاده‌سازی کنترل دسترسی نیست.
- رسانه WebP، sitemap، robots، بخشی از metadata اختصاصی، خروجی standalone و هدرهای پایه امنیت.

## هنوز انجام نشده / نیازمند تکمیل
- احراز هویت و بازیابی رمز، پنل کاربر، پنل مدیر و اعمال RBAC، CMS و CRUD محتوا، Media Library و S3، آپلود امن تصاویر، برآورد قیمت، بلاگ و جستجوی سراسری، مدیریت نظرات و FAQ، صفحات حقوقی نهایی، Analytics و برنامه اجرایی بازیابی پشتیبان.
- محتوای خدمات و پروژه‌ها فعلاً در فایل منبع است، نه CMS دیتابیسی. تصاویر نمونه به عنوان پروژه تأییدشده معرفی نمی‌شوند. هیچ آمار، نظر یا اطلاعات تماس ساختگی ارائه نشده است.
- API ثبت درخواست پیاده‌سازی شده اما تست یکپارچه روی PostgreSQL و ارسال واقعی هنوز انجام نشده است. مدل Session به تنهایی احراز هویت نیست.
- نیاز به CAPTCHA یا محدودیت edge در انتشار عمومی، پاک‌سازی دوره‌ای RateLimit و تعیین سیاست نگهداری داده وجود دارد. محدودیت فعلی حداکثر ۳ درخواست/شماره/ساعت و ۱۰۰ درخواست/سایت/ساعت است؛ تضمین مقابله کامل با حملات توزیع‌شده نیست.
- فایل‌های Docker و SQL ایجاد شده‌اند اما اجرای Docker، migration روی سرور و restore هنوز تست نشده‌اند.
- QA بصری مرورگر، موبایل، WCAG، Lighthouse و تست انتهابه‌انتهای همه مسیرهای درخواستی هنوز کامل نیست.

## تست‌های این مرحله
- `next build`: موفق پس از اصلاح سازگاری params در Next 15 و خطاهای TypeScript.
- `tsc --noEmit`: موفق.
- `prisma validate`: موفق با URL آزمایشی (بدون اتصال دیتابیس).
- `npm audit`: صفر هشدار شناخته‌شده پس از overrides وابستگی‌ها؛ تضمین امنیت کامل نیست.
- نتیجه smoke test محلی در `docs/smoke-test.json` ثبت می‌شود.

قبل از انتشار عمومی باید موارد تکمیل‌نشده، هویت کسب‌وکار، مجوز تصاویر، اطلاعات تماس و زیرساخت واقعی بررسی شوند.
